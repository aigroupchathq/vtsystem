# 07 — Iconography System: VEDIC TREE OS

## 1. Icon Library Standard

VEDIC TREE OS standardizes exclusively on **Lucide Icons** (`lucide-react`) for maximum visual consistency, clean geometry, and zero-bundle bloat via tree shaking.

---

## 2. Icon Sizing Tokens

| Token | Class | Size (px) | Usage |
|---|---|---|---|
| `icon-xs` | `h-3.5 w-3.5` | `14px` | Inline table indicators, micro badges |
| `icon-sm` | `h-4 w-4` | `16px` | Standard button leading/trailing icons, inputs |
| `icon-md` | `h-5 w-5` | `20px` | Sidebar navigation items, card headers |
| `icon-lg` | `h-6 w-6` | `24px` | Topbar action icons, modal headers |
| `icon-xl` | `h-8 w-8` | `32px` | KPI card hero icons, quick action circles |
| `icon-hero`| `h-12 w-12` | `48px` | Empty states, success celebration screens |
