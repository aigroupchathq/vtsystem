## 🏛️ System Overview

Vedic Tree OS is designed for school networks, multi-campus educational institutions, and franchisee operations. Built with strict role-based access control (RBAC), multi-tenant isolation, and a qualitative developmental paradigm that replaces toxic percentile competition with human-centered formative growth.

### Core Modules

1. **Network Overview**: High-level governance, campus comparison, fee collection telemetry, and operational health.
2. **Executive Centre Overview**: Micro-analytics per campus (Panvel, Baner, Kothrud) with staff utilization, occupancy, and compliance.
3. **Student 360 & Vedic Tree Development Compass**: 
   - 4-quadrant qualitative development continuum (`Emerging`, `Developing`, `Proficient`, `Exemplary`).
   - Zero radar charts, zero emotional percentages, zero peer rankings.
   - Strict non-clinical educational safeguarding disclaimer.
   - Persona-isolated financial and pastoral views.
4. **Admissions CRM**: 10-stage admissions funnel with inquiry intake, tour booking, fee estimation, and enrollment.
5. **Academics Hub**: Lesson planning, homework grading, formative & summative assessments, report card generation, and Teacher My Day.
6. **Attendance & Leave Hub**: Classroom roll call, staff biometric logs, leave balance tracking, and configurable policy engine.
7. **School Operations & Facilities**: Asset management, stock inventory, facility booking, maintenance tickets, visitor passes, and incident reporting.
8. **Finance & Institutional Ledger**: Invoicing, online fee collection (Razorpay, Stripe, Cash, Cheque), fee separation guarantees, and revenue ledgers.
9. **Communication Center**: Broadcast announcements, SMS/WhatsApp/Email notifications, emergency alerts, and delivery analytics.
10. **HRMS Faculty Directory**: Faculty directory, department allocation, credentials, qualifications, and attendance logs.

## 🎨 Design System

Vedic Tree OS follows a dignified 3-tier surface hierarchy:
- **Level 1 Canvas**: Warm Ivory (`#FBF8EF`)
- **Level 2 Surfaces**: Elevated Pure White (`#FFFFFF`) with hairline borders (`#E6DFD1`)
- **Level 3 Inset Areas**: Subtle Cream (`#F8F5EE`)
- **Architectural Shell**: Deep Forest Green (`#0B2F29`)
- **Institutional Accent**: Antique Gold (`#C29B38`)
- **Typography**: Playfair Display (Headings) + Plus Jakarta Sans (UI & Body) + Monospace (IDs & Ledger Math only)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm 9+

### Installation & Local Development

```bash
# Clone the repository
git clone https://github.com/aigroupchathq/vtsystem.git
cd vtsystem

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Quality Assurance & Testing

```bash
# Run complete test suite (284 tests across unit, integration, and security layers)
npm test -- --run

# Compile production bundle
npm run build
```

## 🔒 Security & Governance

- **Multi-Tenant Campus Isolation Barrier**: Strict cryptographic and tenant boundary enforcement preventing cross-campus data leakage.
- **Safeguarding Data Protection**: Sensitive pastoral notes and safeguarding records are strictly protected behind Tier-4 RBAC barriers.
- **Financial Boundary Separation**: School fees and institutional collections are structurally segregated under Constitution §14 guidelines.
